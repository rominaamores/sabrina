# Proyecto

Sitio web estático de una marca con **Astro 7**, **Tailwind CSS 4** y **Motion 14**.
Lo trabaja un estudiante que sabe HTML y CSS, pero está aprendiendo Astro:
cuando uses algo propio de Astro (props, `map()`, `class:list`, `<slot />`), explícalo en una frase.

## Quién decide

**El estudiante decide; tú ejecutas.** Toda decisión de diseño o contenido (colores, fuentes, textos, imágenes, orden de secciones, animación) sale del brief (`pack/brief.md`) o del prompt.
Si falta un dato, pregunta. Puedes sugerir opciones, pero no apliques ninguna hasta que el estudiante elija.

## Prohibido

- Inventar textos, colores, fuentes o imágenes; buscar datos personales en el equipo, en git o en otros archivos.
- Instalar paquetes o usar CDNs sin preguntar antes (nada de React, Vue, Bootstrap, jQuery, librerías de iconos).
- Crear `tailwind.config.js`: Tailwind 4 se configura en `src/styles/global.css`.
- Usar Google Fonts, imágenes o scripts de URLs externas.
- Ejecutar `npm run dev`: el estudiante ya lo tiene abierto en otra terminal.
- Modificar `package.json`, `astro.config.mjs`, `tsconfig.json`, `.prettierrc.json`, `.vscode/`, `herramientas/` o `.clinerules/` sin que lo pidan.
- Modificar algo dentro de `pack/`: es el material del estudiante, solo se lee.
